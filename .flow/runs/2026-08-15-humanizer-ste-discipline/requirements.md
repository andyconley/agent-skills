# Requirements

## Problem

The writing skills know many AI-shaped prose failures but still rely too much on agent judgment. Recent sessions showed misses in mirrored rhythm, stance headings, aphoristic closers, signpost nominalization, and similar constructions.

## Confirmed Scope

- Update both `humanizer` and `doc-flow-review` where relevant.
- Make construction sweeps mandatory in normal mode.
- Add STE-inspired discipline inside the skills. Do not claim full ASD-STE100 compliance.
- Update Vale rules, regression fixtures, README/help, validation, remote repo, and local install.
- Carry the work through commit, push, merge/sync, and install for Codex and Claude Code.

## Non-goals

- Full ASD-STE100 dictionary or compliance enforcement.
- A separate STE skill or output style.
- A generic AI detector.
- Broad prose regexes that flag ordinary text without a clear fix.
