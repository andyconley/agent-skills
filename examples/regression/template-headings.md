# Regression: Template Headings

## Bad Source

```md
## Key takeaways
## Problems worth fixing
## Lower-confidence observation (worth a pass, not blocking)
## What's already correctly structured
## What would change this conclusion
```

## Why It Fails

- The headings sound like a polished review framework.
- The labels make the reviewer visible instead of orienting the reader.

## Expected Shape

```md
## Summary
## Problems to fix
## Needs investigation
## Good structure
## What to watch
```

## Pass Checks

- Headings use short working labels.
- No `worth` headings remain.
- No heading explains the reviewer's confidence as a performance.
